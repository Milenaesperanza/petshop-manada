# Petshop Manada

Petshop Manada es un e-commerce desarrollado con React, orientado a la venta de productos para mascotas: perros y gatos.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- HTML
- CSS

## Instalación y ejecución

1. Clonar el repositorio:

git clone [https://github.com/Milenaesperanza/petshop-manada]

2. Ingresar a la carpeta del proyecto:

cd petshop-manada

3. Instalar las dependencias:

npm install

4. Ejecutar el proyecto:

npm run dev

Luego abrir en el navegador la URL local que muestra Vite en la terminal.
